# pastelsiege
A 3D shooter game, with a pastel colour scheme. Created by potatoman.

## Multiplayer relay

Players connect directly when they can. On networks that block that, like school Wi-Fi, the game goes through a small relay server that runs on a homelab behind a Cloudflare Tunnel. See [relay/README.md](relay/README.md) for setup. Without it the game works as before, with direct connections only.
